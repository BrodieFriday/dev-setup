# Dev Setup

My personal development environment setup scripts for macOS (and Linux-compatible).

This repository contains scripts and configurations to quickly set up a productive development environment with Zsh, Node.js, Java tools, and VS Code.

## What's Included

- **`shell_setup.sh`** — Main setup script for shell environment
- **`.zshrc`** — Customized Zsh configuration (with Oh My Zsh)
- **`code_extensions.sh`** — Installs a curated list of VS Code extensions

## Features

- **Oh My Zsh** with Robby Russell theme
- **nvm** (Node Version Manager)
- **SDKMAN!** for Java and JVM tools
- **Homebrew** package manager
- Curated VS Code extensions for:
  - Java development
  - Python
  - Web/Svelte/Angular
  - Git tools
  - Themes & productivity
